# Implemented features

| Feature | Backend | Frontend routes |
|---------|---------|-----------------|
| Login / JWT auth | `AuthController` `POST /api/auth/login` `{ userId, password }` ([AllowAnonymous]); `AppUserRepository.GetCredentialAsync` (exact, case-sensitive UserId; PasswordHash + RoleIds, backend-only); SHA-256 compared in constant time; unknown / inactive / wrong password → same 401 「帳號或密碼錯誤」; HS256 JWT from `Data/AccessTokenBuilder.cs`: `sub` = UserId, `name` = UserName, one `role` per `AppUserRole.RoleId`, 24 h. Key = `SysConfig` appConfig `symmetricSecurityKey` (`Data/SigningKey.cs`, ≥ 32 bytes), read per request for both signing and validation (`SysConfigSigningKeyManager` feeds JwtBearer). `MapControllers().RequireAuthorization()`: every endpoint needs a Bearer token except `[AllowAnonymous]` (login, API-key ingest `POST /api/agent-token-usage`). Role-enforced endpoints: `POST /api/auth/reset-password` `{ userId }` (`[Authorize(Roles = "Admin")]`, 403 otherwise; hash = SHA-256 of SysConfig appConfig `defaultPassword` read per call via `Data/DefaultPassword.cs`, PasswordUpdatedTime = now, 204 no body). Other endpoints, incl. AppUsers / AppRoles CRUD, only need a valid token | `/login` (public, no shell). `core/auth/`: `AuthService` (profile in sessionStorage `auth-profile`, roles decoded from the token), `authInterceptor` (Bearer on API calls; 401 → `sessionStorage.clear()` + `/login?returnUrl=`), `authGuard` (`canActivateChild` on every other route; missing / expired token → `/login`). Header shows UserName + 登出; nav groups with `role` (系統管理 Admin → `Admin`) hidden without it |
| My Profile (header › 我的資料) | `PUT /api/auth/profile` `{ userName }` on `AuthController` (needs JWT): UserId only from the token (`sub` → `ClaimTypes.NameIdentifier`), body has no UserId / roles; UserName trimmed, required (whitespace → 400), ≤ 200; `AppUserRepository.UpdateUserNameAsync` touches only UserName; returns `{ userId, userName }`; token is not re-issued (its `name` claim keeps the old name until next login); `POST /api/auth/change-password` `{ currentPassword, newPassword, confirmPassword }` (JWT user; checks SHA-256(current) = stored hash, then `Data/PasswordPolicy.cs` (≥ 8 chars, 3 of 4 classes A–Z / a–z / 0–9 / symbol; bilingual message), then new = confirm; any failure → 400 and nothing changes; success → PasswordHash = SHA-256(new), PasswordUpdatedTime = now (UTC, `TimeProvider`), 204 with no body) | `/my-profile` (guarded): 使用者帳號 + 角色 (from the token) read-only, 使用者名稱 editable; save → `AuthService.updateProfile` updates sessionStorage `auth-profile` and the header name; 變更密碼 panel (password inputs, rule mirrored in `core/utils/password-policy.ts`, bilingual hint turns red on failure, API message inline) |
| AppUser (系統管理 Admin › 使用者) | `AppUsersController`, `AppUserRepository`, `SysConfigRepository`; n-n roles via `AppUserRole`; backend-only PasswordHash (SHA-256 of `SysConfig` appConfig `defaultPassword`); password reset to default via `POST /api/auth/reset-password` (Admin only, see Login row); 重設密碼 (detail) and 重設為預設密碼 (edit toolbar) shown only to Admins; `GET /api/lookups/app-roles` | `/app-users`, `/app-users/new`, `/app-users/:id`, `/app-users/:id/edit` |
| AppRole (系統管理 Admin › 角色) | `AppRolesController`, `AppRoleRepository`; n-n users via `AppUserRole`; `GET /api/lookups/app-users` | `/app-roles` (accepts `?userId=`), `/app-roles/new`, `/app-roles/:id`, `/app-roles/:id/edit` |
| PublishStatus (系統管理 Admin › 發布狀態) | `PublishStatusesController`, `PublishStatusRepository`; user-supplied tinyint pkid; delete → 409 via `ReferenceConflictException` (SQL 547); `GET /api/lookups/publish-statuses` | `/publish-statuses`, `/publish-statuses/new`, `/publish-statuses/:id`, `/publish-statuses/:id/edit` |
| Partner (課程管理 Course › 合作廠商) | `PartnersController`, `PartnerRepository`; smallint IDENTITY pkid; delete → 409 via `ReferenceConflictException`; `GET /api/lookups/partners` | `/partners`, `/partners/new`, `/partners/:id`, `/partners/:id/edit` |
| CourseGroup (課程管理 Course › 課程群組) | `CourseGroupsController`, `CourseGroupRepository`; smallint IDENTITY pkid; delete → 409 via `ReferenceConflictException`; `GET /api/lookups/course-groups` | `/course-groups`, `/course-groups/new`, `/course-groups/:id`, `/course-groups/:id/edit` |
| Course (課程管理 Course › 課程) | `CoursesController`, `CourseRepository`; multi-map FK nav objects; n-n `CourseInCertification` / `CourseJobCategories`; bad FK → 400 via `InvalidReferenceException`; delete → 409; `GET /api/lookups/certifications`, `/job-categories` | `/courses`, `/courses/new`, `/courses/:id`, `/courses/:id/edit` (accepts `?partnerPkid=`, `?courseGroupPkid=`, `?publishStatusPkid=`) |
| FeaturedPromoItem (首頁 Home › 上稿作業) | `FeaturedPromoItemsController`, `FeaturedPromoItemRepository`; query by `trainingCenterPkid` + `weekOf` (Mon–Sun); UNIQUE date/center/slot → 409 via `DuplicateKeyException`; `POST /{id}/move-up`, `/move-down` swap slots in one UPDATE; `GET /api/lookups/training-centers`, `/promotions?keyword=` | `/featured-promo-items` only — single weekly-schedule page with inline Edit/New/Paste form (no detail/new routes) |
| AgentTokenUsage (代理用量 Agent › 代理 Token 用量) | `AgentTokenUsageController`, `AgentTokenUsageRepository`; ingest `POST /api/agent-token-usage` guarded by `AgentApiKeyFilter` (X-Api-Key, 401 before validation 400); MERGE upsert on (SessionId, UsageDate, Model); "today in Taipei" from injected `TimeProvider`; `POST /api/agent-token-usage/report` groups by user/date/project/model, filters by date range, user, project, model; lookups `agent-token-projects` / `agent-token-models` (distinct, ascending); Cost computed on ingest by the shared `CostCalculator` (`Data/CostCalculator.cs`); client `tools/token-report/` (SessionEnd hook + worker + installer, see `docs/setup-notes.md`) | `/agent-token-report` only — read-only report; filter drawer 日期 (defaults to the current month) / 使用者 / 專案 / 模型; 合計 row over all filtered rows; 成本 (USD) column with 「未定價」 / 「部分用量未定價」 warning; filters, sort, page in sessionStorage |
| ModelPrice (代理用量 Agent › 模型價格) | `ModelPricesController`, `ModelPriceRepository`; int IDENTITY pkid; UNIQUE (Model, EffectiveFrom) → 409 「此模型在該生效日已有定價」; every create/update/delete re-prices the affected model(s)' AgentTokenUsage rows in the same transaction (both names on a rename) via `CostCalculator.Cost` passed in as a `CostFunction` | `/model-prices`, `/model-prices/new`, `/model-prices/:id`, `/model-prices/:id/edit` |
| Row Audit (cross-cutting) | `Data/RowAuditWriter.cs` writes one `RowAudit` row per Insert / Update / Delete in every CRUD repository (same transaction; see `docs/conventions.md`); `RowAuditController` `GET /api/rowaudit?tableName=&pkid=` → `{ dateTime, userName, actionType, actionDesc }` newest first, `RowAuditRepository` | No route: `RowAuditBadgeComponent` (`core/row-audit/`) next to the title of every detail page and edit form (and the inline FeaturedPromoItem form for existing items); shows the latest change, click → dialog with the full trail |
